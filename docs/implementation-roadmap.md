# Market Flick AI — Delivery Roadmap

## Phase 0 — Foundation
Define workspace/project permissions, source provenance, research snapshots, audit events, and shared TypeScript contracts. Add connector consent and encrypted secret handling before ingestion.

## Phase 1 — Research MVP
Ship project onboarding, source selection, asynchronous research runs, source cards, citation-aware AI summaries, demand/competitor/geography templates, and report export. Success: a user completes a cited market report from a project.

## Phase 2 — Growth intelligence
Add signal watchlists, historical trends, opportunity scoring, recommendation queue, 30/60/90-day plans, notifications, and integrations with analytics/search/ad data. Success: every recommendation links to evidence and has owner/status.

## Phase 3 — Investor and predictive suite
Add company profiles, comparable-company sets, thesis/risk models, forecast scenarios, confidence intervals, evaluation/back-testing, and disclosure-safe investor reports. Success: forecasts expose assumptions and uncertainty; no output presents personalised investment advice.

## Phase 4 — Pitch Deck Studio
Add research briefs, section/slide generation, editable canvas, source-linked charts, branded templates, proposal packages, PDF/PPTX export, secure sharing, view events, and revocation. Success: research snapshot to investor-ready deck is traceable end-to-end.

## Phase 5 — Enterprise
Add SSO, roles, white label themes, approval workflows, data retention controls, usage metering, multi-workspace governance, and model evaluation dashboards.

## Build order
1. Database schema and auth. 2. Research run and sources APIs. 3. Frontend types/services. 4. Research UI. 5. Reports. 6. Signals/recommendations. 7. Forecasts. 8. Investor research. 9. Decks/proposals/sharing.
